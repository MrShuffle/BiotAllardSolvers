# Biot Allard Solvers

This repository contains the implementation of the FEM examples shown and discussed in the articles:

Stokke, J. S., Bause, M., Radu, F. A., 2026. Convergence of a continuous Galerkin method for the Biot-Allard poroelasticity system (arXiv:2504.06763). arXiv preprint. 

https://doi.org/10.48550/arXiv.2504.06763 New version to appear.


---

The code uses FreeFem++ (https://freefem.org/) Hecht, F., 2012. New development in freefem++. J. Numer. Math. 20(3-4), 251–265.
