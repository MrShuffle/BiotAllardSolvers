# Biot Allard Solvers

This repository contains the implementation of the FEM examples shown and discussed in the articles:

Jakobsen, M., Stokke, J.S., Kumar, K., Radu, F.A., 2026. Frequency domain Biot–Allard equations for isotropic and anisotropic poroelastic media: Two-field formulations and iterative splitting. Comput Geosci 30, 99. 

https://doi.org/10.1007/s10596-026-10490-x


Stokke, J. S., Bause, M., Radu, F. A., 2025. Convergence of a continuous Galerkin method for the Biot-Allard poroelasticity system (arXiv:2504.06763). arXiv preprint. 

https://doi.org/10.48550/arXiv.2504.06763


---

The code uses FreeFem++ (https://freefem.org/)
